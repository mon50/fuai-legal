This Privacy Policy (the "Policy") describes how information about users (each a "User") is handled in fuai (the "App"). The App is developed and operated by an individual (the "Operator").

The App suggests brands that resonate with the aesthetic a User expresses in words and images. By its nature, the scenes a User writes and the images a User selects are sent to the Operator's server to generate suggestions. See §1.2 for details.

1. Information We Handle

The Operator handles the following information to the extent necessary to provide the App.

1.1 Information stored on your device

  • The list of brands the User has saved (archived) and the brands the User has marked as "not for me" so they are excluded from future suggestions.
  • The taste profile the App learns from the User's input (data describing the User's preferences), and the history of past suggestions (suggested brand cards).
  • Scene texts entered during onboarding, and in-app settings.

This data is stored only on the User's device (in a SQLite database and the OS secure storage) and is not stored on the Operator's server.

1.2 Information sent to the server to generate suggestions

When the User requests brand suggestions, the following information is sent over the Internet to the server operated by the Operator (stateless endpoints on Cloudflare Workers).

  • Scene input: the scene text the User entered, and the images the User optionally selected from the photo library (converted and downscaled to JPEG on the device, up to 3 images). The photo library is accessed only when the User performs this action, and only the images the User selects are handled.
  • Information used to refine suggestions: identifiers of saved and excluded brands, learned taste traits, and scene texts entered during onboarding.
  • Taste profile generation: when generating a profile summary from the User's saved brands and taste traits, that information.

The Operator's server forwards the received information to OpenAI's API (large language models and embedding models), searches the brand database prepared by the Operator, and returns the results to the User's device. The server does not persist the received content.

When displaying the official-site image (OGP image) of a suggested brand, the image is fetched via the Operator's server. Such requests contain only the brand's URL and none of the User's input.

1.3 Information we do not collect

  • Name, address, phone number, date of birth, gender, email address, or other registration data (the App has no account feature).
  • Advertising identifiers such as IDFA / Advertising ID (the App shows no ads).
  • Location, contacts, microphone, or camera access (the photo library is accessed only as described in §1.2).
  • Usage data via crash reporting or analytics tools (Firebase / Crashlytics / Google Analytics, etc.).
  • Credit card or other payment information (the App has no paid features; everything is free).

2. Purposes of Use

  • Information sent under §1.2 is used solely to generate the brand suggestions and taste profile presented to the User.
  • The Operator does not use the information for training or improving machine-learning models, advertising, providing profiles to third parties, or any other secondary purpose.

3. Third Parties and Cross-Border Transfers

3.1 Third-party processors

To generate suggestions, the Operator forwards information sent by the User to the following processors. They act on the Operator's behalf and are not independent recipients.

  • OpenAI, L.L.C. (United States)
    • Purpose: generating brand suggestions and taste profiles, and computing embeddings (vectors) that capture the meaning of scenes.
    • The Operator relies on OpenAI's terms under which data submitted via the API is not used to train OpenAI's models (the default behavior under the OpenAI Business Terms / API Data Usage Policies).
  • Cloudflare, Inc. (United States)
    • Purpose: the execution platform for the Operator's server (Cloudflare Workers), the brand database, and vector search.
    • Cloudflare does not persist the User's input.

The Operator does not sell, transfer, or share the User's information with any other third party (advertisers, data brokers, or other companies).

3.2 Transfers to foreign countries

The processors above are located in the United States. OpenAI and Cloudflare each take measures necessary to protect personal information under their own privacy policies. Please refer to their privacy policies for details.

4. Storage Location and Retention

4.1 On-device data

  • Saved brands, the taste profile, and suggestion history are stored only on the User's device.
  • Saved brands can be deleted individually in the App at any time. Uninstalling the App erases all on-device data.
  • The Operator does not unilaterally impose a retention period.

4.2 Server side

  • The Operator's server does not persist the User's input (it is discarded immediately after processing).
  • To prevent abuse, per-token rate-limit counters are kept briefly (on the order of hours) in a Cloudflare Durable Object; they contain none of the User's input.
  • Brands' official-site images (OGP images) are cached on the server for a limited time; they are the brands' content and contain no User information.

5. Security Measures

  • Encryption in transit: all communication between the device and the Operator's server, and between the Operator and OpenAI, is encrypted with HTTPS (TLS).
  • Protection of on-device data: saved brands and the taste profile are stored in a SQLite database on the device. Their protection relies on the disk encryption provided by the device OS (File Protection on iOS / File-Based Encryption on Android). Additional app-level encryption (e.g., SQLCipher) is not currently implemented. We strongly recommend enabling a lock-screen passcode / biometrics and keeping the OS up to date.
  • Access control: the Operator's server requires an auth token and rejects unauthenticated requests (returns 401).
  • Server-side data minimization: by not persisting data, the design minimizes the risk of a server-side data breach.

6. Your Rights

Users have the following rights.

  • Access: the archive and profile screens in the App show the data stored on the device.
  • Deletion: saved brands can be deleted individually in the App at any time. Uninstalling the App erases all on-device data. Because the server holds no data in the first place, no deletion request to the server is necessary.
  • Rectification: the taste profile is updated through the User's own actions — saving or deleting brands and marking suggestions as "not for me."
  • Objections and complaints: complaints about this Policy or the handling of personal information can be sent to the contact in §8.
  • Supervisory authority: Users in Japan may lodge a complaint with the Personal Information Protection Commission; Users in the EU may lodge one with their local data protection authority.

Do-not-sell declaration (CCPA): the Operator does not sell the personal information of any User, including California residents.

7. Revisions

  • The Operator may revise this Policy in response to legal changes, service improvements, and the like.
  • Revisions are recorded with their date and content in the "Revision history" section of this page.
  • For material changes (additional data collected, additional purposes, additional processors, weakened security measures, etc.), separate notice may be given in the App or on the store listing.
