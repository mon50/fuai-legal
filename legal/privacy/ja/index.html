本プライバシーポリシー（以下「本ポリシー」）は、fuai（風合い、以下「本アプリ」）における、 本アプリ利用者（以下「利用者」）の情報の取り扱いについて定めるものです。 本アプリは個人が個人として開発・運営しています（以下「当方」）。

本アプリは、利用者が言葉や画像で表現した「好みの雰囲気（情景）」をもとに、 AI を介して共鳴するブランドを提案するアプリです。その性質上、利用者が入力した情景や 選択した画像は、提案の生成のために当方のサーバーへ送信されます。詳細は §1.2 をご確認ください。

1. 取得する情報

当方は、本アプリの提供に必要な範囲で次の情報を取り扱います。

1.1 端末内に保存される情報

  • 利用者が保存（アーカイブ）したブランド、および「違う」と評価して以後の提案から 除外したブランドの一覧。
  • 利用者の入力から本アプリが学習したテイストプロファイル（好みの傾向を表すデータ）、 および過去の提案の履歴（提案されたブランドカード）。
  • オンボーディングで入力した情景テキスト、およびアプリ内設定。

これらは利用者の端末内（SQLite データベースおよび OS のセキュア領域）にのみ保存され、 当方のサーバーには保存されません。

1.2 提案生成のためにサーバーへ送信される情報

利用者がブランドの提案を求める操作を行う際、提案の生成のため次の情報がインターネットを 通じて当方の運用するサーバー（Cloudflare Workers 上のステートレスエンドポイント）へ 送信されます。

  • 情景の入力: 利用者が入力した情景テキスト、および利用者が写真ライブラリから 任意で選択した画像（端末内で JPEG に変換・縮小した画像データ、最大 3 枚）。 写真ライブラリへのアクセスはこの操作を行ったときに限られ、利用者が選択した画像のみを取り扱います。
  • 提案の調整に用いる情報: 保存済み・除外済みブランドの識別子、 学習済みのテイスト特性、オンボーディングで入力した情景テキスト。
  • テイストプロファイルの生成: 保存済みブランドとテイスト特性をもとに プロファイル文を生成する際、それらの情報。

当方のサーバーは、受信した情報を OpenAI 社の API（大規模言語モデルおよび埋め込みモデル）へ 転送し、当方が用意したブランド情報のデータベースを検索して、提案結果を利用者の端末へ 返却します。サーバーは受信した内容を永続化しません。

なお、提案されたブランドの公式サイトの画像（OGP 画像）を表示する際、当方のサーバーを 経由して取得します。この要求に含まれるのはブランド側の URL のみであり、利用者の入力内容は 含まれません。

1.3 当方が取得しない情報

  • 氏名、住所、電話番号、生年月日、性別、メールアドレス等の登録情報（本アプリにアカウント機能はありません）。
  • IDFA / Advertising ID 等の広告識別子（本アプリに広告表示はありません）。
  • 位置情報、連絡先、マイク、カメラへのアクセス権（写真ライブラリは §1.2 に記載の場合に限ります）。
  • クラッシュレポートや解析ツール（Firebase / Crashlytics / Google Analytics 等）を介した利用状況。
  • クレジットカード情報その他の決済情報（本アプリに課金機能はなく、全機能を無料で提供します）。

2. 利用目的

  • §1.2 で送信された情報は、利用者へ提示するブランド提案およびテイストプロファイルを生成する目的にのみ利用します。
  • 当方は、機械学習モデルの学習・改善、広告配信、第三者へのプロファイル提供、その他の二次利用を一切行いません。

3. 第三者提供と外部送信

3.1 第三者処理者

当方は、提案の生成に必要な範囲で、利用者から送信された情報を次の第三者処理者へ転送します。 これらは当方が委託する処理者であり、独立した提供先ではありません。

  • OpenAI, L.L.C.（所在地: アメリカ合衆国）
    • 用途: ブランド提案・テイストプロファイルの生成、および情景の意味を捉えるための埋め込み（ベクトル）計算。
    • OpenAI の API 利用規約上、API 経由で送信された情報は OpenAI のモデル学習目的に利用されない ことを当方は前提としています（OpenAI Business Terms / API Data Usage Policies に基づく 既定挙動）。
  • Cloudflare, Inc.（所在地: アメリカ合衆国）
    • 用途: 当方のサーバー（Cloudflare Workers）、ブランド情報データベース、およびベクトル検索の実行基盤。
    • Cloudflare 側で利用者の入力内容を永続化することはありません。

上記以外の第三者（広告主、データブローカー、外部企業）に対し、利用者の情報を販売・譲渡・共有 することはありません。

3.2 外国にある第三者への提供

上記処理者はいずれもアメリカ合衆国に所在します。OpenAI 社・Cloudflare 社は、 それぞれ同社のプライバシーポリシーに基づき、個人情報の保護に必要な措置を講じています。 詳細は各社のプライバシーポリシーをご確認ください。

4. 保管場所と保管期間

4.1 端末内データ

  • 保存ブランド、テイストプロファイル、提案履歴は利用者の端末内にのみ保存されます。
  • 保存したブランドはアプリ内でいつでも個別に削除できます。アプリをアンインストールすると、端末内のすべてのデータが消去されます。
  • 当方が保管期間を一方的に設定することはありません。

4.2 サーバー側

  • 当方のサーバーは受信した利用者の入力を永続化しません（処理後直ちに破棄します）。
  • 悪用防止のため、認証トークン単位のレート制御カウンタを Cloudflare Durable Object に短期間（時間単位）保持しますが、これは利用者の入力内容を含みません。
  • ブランド公式サイトの画像（OGP 画像）はサーバー側で一定期間キャッシュされますが、これはブランド側のコンテンツであり、利用者の情報を含みません。

5. 安全管理措置

  • 通信の暗号化: 端末と当方のサーバー間、当方と OpenAI 社の間の通信はいずれも HTTPS（TLS）で暗号化します。
  • 端末内データの保護: 保存ブランドやテイストプロファイルは端末内の SQLite データベースに保存されます。 当該データの保護は、利用者の端末の OS が提供するディスク暗号化（iOS の File Protection / Android の File-Based Encryption）に依存します。 現時点ではアプリレベルでの追加の暗号化（SQLCipher 等）は実装していません。 そのため、端末のロック画面パスコード / 生体認証を有効に設定し、最新の OS にアップデートすることを強く推奨します。
  • アクセス制御: 当方のサーバーは認証トークンを必要とし、未認証の要求は受理しません（401 を返します）。
  • サーバー側のデータ最小化: 永続化を行わない設計により、サーバー側でのデータ漏えいリスクを最小化しています。

6. 利用者の権利

利用者は次の権利を有します。

  • アクセス（開示）: アプリ内のアーカイブ・プロフィール画面から、端末内に保存されたデータを参照できます。
  • 削除: 保存したブランドはアプリ内でいつでも個別に削除できます。アプリをアンインストールすると端末内のすべてのデータが消去されます。サーバーは元々データを保持していないため、削除請求はサーバーに対しては不要です。
  • 訂正: テイストプロファイルは、ブランドの保存・削除や「違う」の評価を通じて、利用者の操作により更新されます。
  • 異議・苦情申立て: 本ポリシーの内容、または個人情報の取り扱いに関する苦情は、本ポリシー第 8 項の問い合わせ窓口へお寄せください。
  • 監督機関への申告: 日本国内の利用者は個人情報保護委員会、EU 域内の利用者は所在地のデータ保護当局に苦情を申し立てることができます。

do-not-sell 宣言（CCPA）: 当方は、米国カリフォルニア州民の個人情報を含め、いかなる利用者の個人情報も第三者へ販売しません。

7. 本ポリシーの改訂

  • 当方は、法令変更・サービス改善等に応じ、本ポリシーを改訂することがあります。
  • 改訂時は、本ページの「改訂履歴」セクションに変更日と変更内容を記載します。
  • 重大な変更（収集情報の追加、利用目的の追加、第三者処理者の追加、安全管理措置の後退 等）が ある場合は、アプリ内またはストア掲載ページで別途案内することがあります。
