# fuai-legal

fuai（風合い）アプリの法的情報（プライバシーポリシー / 利用規約）を
GitHub Pages で公開するための静的サイト。

課金機能が無いため特定商取引法に基づく表記は無い（課金導入時に追加すること）。

## 公開 URL

| ドキュメント | ja | en |
|---|---|---|
| プライバシーポリシー | `/legal/privacy/ja/` | `/legal/privacy/en/` |
| 利用規約 | `/legal/terms/ja/` | `/legal/terms/en/` |

ベース URL: `https://mon50.github.io/fuai-legal/`

## 更新手順

1. 本リポジトリの `legal/` を編集してコミット・push する（ja が正本、en は追随）。
2. 改訂時は各ページ末尾の「改訂履歴」に日付と変更内容を追記する。

> **注意**: 公開前に各文書内の `<<CONTACT_EMAIL>>` を実際の連絡先メールアドレスへ置換すること
> （tsumu / futariseikatsu と共通の一括置換対象）。
